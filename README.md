# BlueLib Catalogue

A simple library catalogue page for BlueCrest College, built with plain HTML, CSS and JavaScript (no frameworks).

**Student:** YOUR NAME HERE | **ID:** YOUR ID HERE

## Features
- **Book cards:** 6 books stored in a JavaScript array and drawn as cards by JavaScript.
- **Search:** filters books by title as you type.
- **Category filter:** dropdown shows only books from one category.
- **Add book:** form with validation (all fields required, copies must be a whole number of 0 or more) and a clear error message.
- **Borrow button:** reduces copies by 1; at 0 it shows "Out of stock" and the button is disabled.
- **Responsive layout:** 3 cards per row on desktop, 2 on tablet, 1 on mobile (below 600px).
- **CSS variables** for colours and **hover effects** on cards and buttons.
